Sistema para planificar rutas óptimas de recolección de paquetes para agentes postales. Con dos implementaciones, una recursiva y una solución iterativa con pilas.

Solución recursiva:
1. SolucionRecursiva: Es el constructor de la clase y recibe un arbol ya construido como paramaetro.
2. solución: método público que inicia la solución.
3. solución: método privado recusrivo que recorre el árbol y construye la ruta de recolección.
4. NodoEsNatural: método que verifica si el nodo actual tiene un número natural (si es una oficina).

Solución iterativa:
1. recorrerConPila: método que recorre un árbol usando una pila (recorrido en profundidad iterativo).
